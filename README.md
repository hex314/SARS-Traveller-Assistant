# 南非入境申报助手

一个 Chrome 扩展，用于批量填写南非海关旅客申报表（SARS Traveller Declaration）。
公共信息填一次，旅客名单粘贴一次，之后每位旅客单独一个标签页自动完成三步填写。

> 独立第三方辅助工具，与 South African Revenue Service（SARS）无隶属关系。
> **不会自动提交申报**，提交前的核对与确认始终由使用者本人完成。

---

## 功能

- **公共信息复用**：声明类型、旅行方式、口岸、交通工具、证件类型、职业、旅客类型、旅行原因、出发/经停/目的地、到达日期、地址、邮箱，填一次全部旅客通用。
- **真实下拉选项**：从 SARS 页面读取下拉框选项，`Mode of Travel Type` → `Airport` → `Mode of Transport` 自动联动刷新。
- **到达日期约束**：按页面可选范围选择，页面禁用的日期自动置灰，不会填出无效日期。
- **名单批量解析**：直接粘贴 Excel 数据（姓名 / 护照号 / 出生日期 / 手机号），手机号合并单元格时空行自动沿用上一行。
- **一键批量录入**：为每位旅客打开独立标签页并依次填写，数据不会串位。
- **自动翻页**：第一步填完自动进入 Travel Details；进入 Payments Summary 后自动把 Declaration 开关置为 YES，再点 Next。
- **结果报告**：逐位旅客汇报成功填写项与未完成项，失败原因直接显示。

## 安装

### 从源码加载（开发版）

1. 下载或克隆本仓库到本地
2. 打开 Chrome，访问 `chrome://extensions`
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选择本仓库根目录（含 `manifest.json` 的那一层）

### 从商店安装

上架审核中，通过后会在此处补充链接。

## 使用

1. 打开 SARS 旅客申报页：<https://tools.sars.gov.za/sarsonlinequery/traveller>
2. 点扩展图标，点「从 SARS 页面获取下拉框选项（含联动）」
3. 填写公共信息 → 保存
4. 粘贴旅客名单 → 解析旅客数据 → 核对每位旅客信息
5. 点「一键批量录入（打开标签页并自动填写）」，等待状态栏汇报结果
6. 逐个标签页核对护照信息与申报内容，**自行完成最终提交**

> 提示：批量录入会打开多个标签页，请保持弹窗打开直到状态栏显示完成。

## 目录结构

```
manifest.json        扩展清单（MV3）
background.js        Service Worker：标签页编排、批量调度
content.js           页面脚本：字段定位、下拉框/开关操作、三步流程自动化
popup.html/.css/.js  扩展界面：公共信息 + 旅客名单 + 一键批量录入
icons/               扩展图标 16/32/48/128
docs/                隐私政策（GitHub Pages 托管）
store/               上架素材（文案、商店图标、宣传图、截图、打包脚本）
```

## 隐私

- 不收集、不上传、不出售任何数据
- 公共信息与旅客名单仅保存在本机 `chrome.storage.local`
- 主机权限限定为 `https://tools.sars.gov.za/sarsonlinequery/*`
- 无远程代码、无统计 SDK、无广告

完整说明见 [隐私政策](docs/privacy-policy.html)。

## 上架素材

`store/` 目录包含：

- `listing.md` — 商店名称、简短/详细说明、权限理由、数据使用表单答案、审核风险提示
- `icon-128.png` — 商店图标；`promo-440x280.png` — 小宣传图
- `png/` — 1280×800 商店截图（示意稿，可用真机截图替换）
- `assets/` — 图标生成脚本 `make_icons.py`、截图源 HTML
